# INSY 3300 – Introduction to Programming | Python

Python programming coursework focused on problem solving, reusable functions, control flow, validation, file processing, modules, and core data structures.

## Core Technologies

`Python 3` · `Functions` · `Control Flow` · `File I/O` · `Exception Handling` · `Lists` · `Dictionaries` · `Sets` · `Modules`

## Projects & Assignments

### Programming Fundamentals

A group of interactive programs demonstrating foundational Python logic.

**Projects include:**
- subject-popularity calculator
- temperature validation and conversion
- beverage recommender
- even/odd calculator

**Concepts:** functions, user input, arithmetic, conditionals, loops, validation, and string processing.

### Modules, Data Processing & File I/O

Programs focused on reusable code, structured data, and persistent files.

**Projects include:**
- multiplication quiz with random questions and exception handling
- reusable temperature-conversion module
- list-processing exercises using slicing and comprehensions
- file-statistics program that writes, reads, analyzes, and appends numeric data

**Concepts:** modules, imports, random-number generation, lists, comprehensions, file I/O, exception handling, aggregation, and helper functions.

### Dictionaries, Sets & Simulation

Applications using Python data structures for lookup, analysis, and simulation.

**Projects include:**
- fruit-color quiz using a dictionary
- library category analysis using set operations
- 500-roll dice simulation with frequency tracking

**Concepts:** dictionaries, sets, intersections, differences, unions, symmetric differences, sorting, counters, random simulation, and aggregation.

## Skills Demonstrated

- Python application development

- conditional logic and loops
- input validation

- file input/output

- modules and imports

## Running the Programs

Python 3 is required. No third-party packages are needed.

```bash

```

For the temperature module example:

```bash
cd assignment-02

```
